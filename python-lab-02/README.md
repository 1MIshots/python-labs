# Лабораторная работа 2

Ветвления и циклы в Python. Вариант 13 во всех обязательных группах.

## Запуск

Требуется Python 3.14; все учебные программы используют стандартную библиотеку.
Проверено в Windows 10 Pro, Python 3.14.6.

Откройте терминал в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe branch.py
.\.venv\Scripts\python.exe verify.py
```

Числа вводятся с десятичной точкой. При отсутствии отдельного указания
каждое поле вводится с новой строки. Списки и кортежи чисел вводятся одной
строкой через пробел. Пустую строку вводите нажатием Enter.
Программы читают данные без приглашений; порядок ввода описан ниже.
Командный цикл завершайте командой `exit`.

## Программы в порядке выполнения

1. [branch.py](branch.py) — Кусочная функция. Ввести конечное вещественное x от −100 до 100. Вычислить y = 2x² + cos x при x ≤ 0; y = x + 1 при 0 < x < 5; y = sin(2x) − x² при x ≥ 5. Углы заданы в радианах.

2. [season_if.py](season_if.py) — Сезон через if. По целому номеру месяца определить сезон. Для числа вне 1–12 вывести сообщение об ошибке.

3. [season_match.py](season_match.py) — Сезон через match. Решить ту же задачу с помощью match и литеральных образцов.

4. [finite_sum.py](finite_sum.py) — Конечная сумма. Ввести целое n от 0 до 10000 и вещественное 0 < x ≤ 100. Вычислить S = Σ ln(kx)/k² для k от 1 до n.

5. [positive_sum.py](positive_sum.py) — Сумма до сигнального нуля. Последовательно вводить целые числа до первого нуля. Суммировать только положительные; отрицательные пропускать.

6. [sqrt_iteration.py](sqrt_iteration.py) — Итерационное извлечение корня. Для a от 0 до 1000000 вычислить квадратный корень итерациями x_next = (x + a/x)/2 с точностью изменения 10⁻¹⁰ и ограничением 1000 итераций. Сравнить с math.sqrt.

7. [exponential_integral.py](exponential_integral.py) — Экспоненциальный интеграл. Для 0,1 ≤ x ≤ 1 вычислить Ei(x) = γ + ln x + Σ xᵏ/(k·k!), k ≥ 1, где γ = 0,5772156649015329. Точность оценки остатка — 10⁻¹⁰.

8. [individual_01.py](individual_01.py) — Индивидуальное задание 1 вариант 13. Сборщику помидоров за каждый килограмм платят 0,30 руб. при сборе до 50 кг включительно; 0,50 руб. при сборе свыше 50 до 75 кг включительно; 0,65 руб. при сборе свыше 75 до 90 кг включительно; 0,70 руб. при сборе свыше 90 кг и дополнительно премию 20 руб. Ввести массу x от 0 до 1000 кг и определить оплату.

9. [individual_02.py](individual_02.py) — Индивидуальное задание 2 вариант 13. Ввести два натуральных числа x и y. Определить, делится ли x на y без остатка.

10. [individual_03.py](individual_03.py) — Индивидуальное задание 3 вариант 13. Ввести натуральное n, 1 ≤ n ≤ 100000. Найти и вывести все натуральные делители числа.

11. [individual_04.py](individual_04.py) — Индивидуальное задание 4 вариант 13. Вычислить sh(x) = (eˣ − e⁻ˣ)/2 = Σ x²ᵏ⁺¹/(2k + 1)!, k ≥ 0, на отрезке [−1; 1] с оценкой остатка не более 10⁻¹⁰. Использовать рекуррентное получение членов, ограничить их число 1000 и выполнить независимую проверку.

## Входные данные и команды

В `branch.py` — x; в программах сезонов — номер месяца;
в `finite_sum.py` — n, затем x; в `positive_sum.py` — числа до нуля;
в `sqrt_iteration.py` — a; в `exponential_integral.py` — x.
В `individual_01.py` — масса x; в `individual_02.py` — x и y;
в `individual_03.py` — n; в `individual_04.py` — x.
Данные числового формата предполагаются корректными, диапазоны проверяются.
