# Лабораторная работа 3

Работа со строками в Python.

## Запуск

Требуется Python 3.14.Проверено в Windows 10, Python 3.14.

Откройте терминал в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe replace_spaces.py
.\.venv\Scripts\python.exe verify.py
```

Числа вводятся с десятичной точкой. При отсутствии отдельного указания
каждое поле вводится с новой строки. Списки и кортежи чисел вводятся одной
строкой через пробел. Пустую строку вводите нажатием Enter.
Программы читают данные без приглашений; порядок ввода описан ниже.
Командный цикл завершайте командой `exit`.

## Программы в порядке выполнения

1. [replace_spaces.py](replace_spaces.py) — Замена пробелов. Ввести строку и заменить каждый обычный пробел подчёркиванием. Пустая строка допустима.

2. [remove_middle.py](remove_middle.py) — Удаление середины слова. Из непустого слова удалить средний символ при нечётной длине либо два средних символа при чётной. Для пустого ввода вывести ошибку и завершиться с кодом 1.

3. [justify_text.py](justify_text.py) — Равномерное распределение пробелов. Ввести строку из двух или более слов и целую требуемую длину L. Слова разделены обычными пробелами, пробелов по краям и других пробельных символов нет. Исходная длина ≤ L ≤ 10000. Сохранить слова и порядок; распределить пробелы так, чтобы ширины промежутков отличались не более чем на 1, более длинные промежутки находились левее. При равной длине допускается перераспределение существующих пробелов.

4. [individual_01.py](individual_01.py) — Индивидуальное задание 1 вариант 13. Дано предложение. Вывести порядковые номера всех букв «и», находящихся на чётных местах. Каждый номер вывести с новой строки.

5. [individual_02.py](individual_02.py) — Индивидуальное задание 2 вариант 13. Дано предложение, в котором имеются буквы «н» и «к». Определить, какая из этих букв встречается раньше при просмотре слева направо.

6. [individual_03.py](individual_03.py) — Индивидуальное задание 3 вариант 13. Дано слово. Перенести его первую букву в конец слова.

## Входные данные и команды

Везде вводится одна строка. В `justify_text.py` следующей строкой вводится
требуемая длина L. Максимальная длина входной строки — 1000 символов.
В `individual_02.py` по условию присутствуют обе буквы «н» и «к»;
в `individual_03.py` слово непустое. Эти предусловия не заменены произвольным
поведением для недопустимого ввода. `repr` делает пробелы и пустой результат видимыми.
