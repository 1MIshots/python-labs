# Лабораторная работа 5

Работа с множествами и словарями в языке Python. Вариант 13 во всех обязательных группах.

## Запуск

Требуется Python 3.14; все учебные программы используют стандартную библиотеку.
Проверено в Windows 10 Pro, Python 3.14.6.

Откройте терминал в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe set_operations.py
.\.venv\Scripts\python.exe verify.py
```

Числа вводятся с десятичной точкой. При отсутствии отдельного указания
каждое поле вводится с новой строки. Списки и кортежи чисел вводятся одной
строкой через пробел. Пустую строку вводите нажатием Enter.
Программы читают данные без приглашений; порядок ввода описан ниже.
Командный цикл завершайте командой `exit`.

## Программы в порядке выполнения

1. [set_operations.py](set_operations.py) — Операции над множествами. В универсуме U строчных латинских букв заданы A = {b, c, h, o}, B = {d, f, g, o, v, y}, C = {d, e, j, k}, D = {a, b, f, g}. Вычислить X = (A ∩ B) ∪ C и Y = (A ∖ D) ∪ (C̄ ∖ B̄). Дополнения берутся относительно U.

2. [workers.py](workers.py) — Команды для списка работников. Хранить список словарей с полями name — имя, post — должность, year — год приёма. Команды add, list, select N, help, exit добавляют запись, выводят список и отбирают работников со стажем строго больше N лет. Упорядочить записи по имени без учёта регистра.

3. [vowels.py](vowels.py) — Общее задание 1 Гласные. Ввести строку, определить количество русских гласных букв и множество различных встретившихся гласных. Регистр не учитывать.

4. [common_chars.py](common_chars.py) — Общее задание 2 Общие символы. Ввести две строки и вывести множество символов, встречающихся в обеих.

5. [school.py](school.py) — Общее задание 3 Классы школы. Создать словарь «обозначение класса → количество учеников». Изменить число учеников существующего класса, добавить новый класс, удалить класс и определить общее количество учеников.

6. [invert_dict.py](invert_dict.py) — Общее задание 4 Обратный словарь. Ввести словарь с целочисленными ключами и уникальными строковыми значениями. Построить новый словарь, в котором значения становятся ключами, а ключи — значениями.

7. [individual_01.py](individual_01.py) — Индивидуальное задание 1 вариант 13. U — все строчные латинские буквы. A = {a, b, g, k, m, p}; B = {b, e, f, l, r}; C = {k, l, w, x}; D = {e, j, o, p, q, u, v}. Вычислить X = (A ∖ B) ∩ (C ∪ D); Y = (Ā ∩ B̄) ∖ (C ∪ D). Исходные множества не изменять.

8. [individual_02.py](individual_02.py) — Индивидуальное задание 2 вариант 13. Вводятся название кафе и сумма заказа в целых копейках. Построить словарь «кафе → общая выручка», суммируя повторные названия. Ввести неотрицательный порог t, отобрать кафе с выручкой строго больше t и найти все кафе с наибольшей выручкой.

9. [individual_03.py](individual_03.py) — Индивидуальное задание 3 вариант 13. Хранить список словарей: name — строка с фамилией и именем, phone — строка цифр телефона длиной не менее трёх, birth — список трёх целых чисел [день, месяц, год]. После добавления сортировать список по первым трём цифрам телефона. Команда select ФАМИЛИЯ выводит все записи с указанной фамилией без учёта регистра. Предусмотрены также add, list, help, exit.

## Входные данные и команды

`set_operations.py` и `individual_01.py` не требуют ввода: исходные наборы заданы
в коде. Функция calculate позволяет проверять другие наборы в том же универсуме.
`vowels.py` читает одну строку; `common_chars.py` — две строки.

`workers.py`: сначала опорный год (в примерах 2026), затем команды
`add`, `list`, `select N`, `help`, `exit`. После add вводятся имя, должность,
год приёма — по одному полю на строку. select выбирает стаж строго больше N.

`school.py`: n попыток начального ввода; для каждой — класс и количество.
Затем класс и новое количество для изменения; класс и количество для добавления;
класс для удаления. Все поля отдельными строками.

`invert_dict.py`: n, затем n пар целый ключ и непустое строковое значение.
Дубликаты ключей и значений отклоняются.

`individual_02.py`: n заказов, затем для каждого название кафе и целая сумма
в копейках, после всех попыток — целый порог t в копейках. Повторные названия
суммируются, регистр названия учитывается. Неверная запись пропускается.

`individual_03.py`: сначала опорный год, затем команды `add`, `list`,
`select ФАМИЛИЯ`, `help`, `exit`. После add — фамилия и имя (не менее двух слов),
телефон из ASCII цифр длиной не менее 3 и дата dd.mm.yyyy отдельными строками.
Поиск фамилии не учитывает регистр. Телефон остаётся строкой с ведущими нулями.
