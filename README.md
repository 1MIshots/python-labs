## Повторная проверка всех работ

```powershell
python verify_all.py
```

Для отдельных программ откройте папку соответствующей работы и следуйте её README.
Виртуальные окружения не включены в архив: создайте своё командой `python -m venv .venv`.

## Что загрузить на GitHub

Загрузите содержимое этой папки: README.md, verify_all.py, .gitignore и пять
папок python-lab-01–python-lab-05. В каждой работе сохраните исходники,
README.md, verify.py, fixtures.json (если есть), results, .vscode и doc.
Не загружайте .venv, __pycache__, *.pyc, общий ZIP и служебную папку .git
через веб-интерфейс. При git push Git сам использует .git локально.
Один репозиторий может содержать все пять работ.
