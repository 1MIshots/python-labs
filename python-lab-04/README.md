# Лабораторная работа 4

Работа со списками и кортежами в языке Python. Вариант 13.

## Запуск

Требуется Python 3.14.Проверено в Windows 10, Python 3.14.

Откройте терминал в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe selected_sum.py
.\.venv\Scripts\python.exe verify.py
```

Числа вводятся с десятичной точкой. При отсутствии отдельного указания
каждое поле вводится с новой строки. Списки и кортежи чисел вводятся одной
строкой через пробел. Пустую строку вводите нажатием Enter.
Программы читают данные без приглашений; порядок ввода описан ниже.
Командный цикл завершайте командой `exit`.

## Программы в порядке выполнения

1. [selected_sum.py](selected_sum.py) — Сумма элементов с ограничением модуля. Ввести ровно десять целых чисел. Найти сумму элементов, модуль которых меньше пяти. Решить циклом и проверить выражением генератором.

2. [between_extrema.py](between_extrema.py) — Элементы между первыми экстремумами. В непустом списке целых чисел найти количество положительных элементов строго между первым минимальным и первым максимальным элементами. Нумерация индексов начинается с нуля.

3. [filter_sort.py](filter_sort.py) — Фильтрация и сортировка копии. Удалить отрицательные элементы, отсортировать оставшиеся по убыванию и сохранить исходный список. Пустой ввод допустим.

4. [sensor_readings.py](sensor_readings.py) — Список записей кортежей. Ввести положительное число измерений, затем отдельно название датчика и конечную вещественную температуру каждого. Построить список кортежей (название, температура). Вычислить среднюю температуру и вывести записи строго выше неё по убыванию температуры.

5. [individual_01.py](individual_01.py) — Индивидуальное задание 1 вариант 13. Ввести ровно десять целых чисел. Найти сумму и количество элементов, модуль которых меньше трёх или которые делятся на девять без остатка.

6. [individual_02.py](individual_02.py) — Индивидуальное задание 2 вариант 13. В непустом списке вещественных чисел определить количество нулевых элементов и сумму элементов, расположенных после первого минимального элемента. Отсортировать копию списка по возрастанию модулей элементов.

7. [individual_03.py](individual_03.py) — Индивидуальное задание 3 вариант 13. Ввести кортеж оценок от 2 до 5. Сформировать кортеж частот (количество двоек, троек, четвёрок, пятёрок), распаковать его в четыре переменные и вывести результаты. Пустой кортеж допустим.

## Входные данные и команды

Все программы, кроме `sensor_readings.py`, читают одну строку чисел.
`sensor_readings.py` читает положительное n, затем n пар: название датчика,
температура — отдельными строками. В программе частот оценки допустимы от 2 до 5.
Пустой ввод разрешён для фильтрации и кортежа оценок, для поиска минимума — ошибка.
